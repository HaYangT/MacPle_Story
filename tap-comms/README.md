# tap-comms

This directory is the shared file workspace for `tap` agent collaboration.

Use these folders for durable agent-to-agent records:

- `inbox/` for direct messages and handoffs.
- `reviews/` for code review artifacts.
- `findings/` for discoveries outside the current task.
- `handoff/` for session handoff notes.
- `retros/` for retrospectives.
- `archive/` for archived messages.

Runtime files such as heartbeats and claims are ignored.
