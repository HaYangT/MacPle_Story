# BuffIcons

이 폴더에 **버프 아이콘 PNG**를 넣으면 앱의 "경험치 버프 알림" 메뉴에
자동으로 프리셋으로 등장합니다. (별도 코드 수정 불필요)

규칙
- 형식: PNG
- 파일명이 곧 메뉴에 표시되는 이름이 됩니다. (예: `경험치2배.png` → "경험치2배")
- 숫자 오버레이가 없는 **깨끗한 아이콘**을 넣으세요. (라이브 화면의 남은 시간 숫자는
  OpenCV 매칭이 알아서 견딥니다)

현재 들어 있는 `경험치2배.png`, `럭키데이.png`는 동작 확인용 예시이므로
실제 아이콘으로 교체/삭제하셔도 됩니다.
