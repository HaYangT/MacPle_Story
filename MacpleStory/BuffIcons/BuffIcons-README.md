# BuffIcons

이 폴더에 **버프 아이콘 PNG**를 넣고, **`BuffCatalog.json`** 에 목록을 적으면
앱의 "경험치 버프 알림" 메뉴에 프리셋으로 등장합니다.

## BuffCatalog.json

묶음(그룹)을 직접 정의합니다. `icons`에 PNG 파일명(확장자 제외)을 적습니다.

```json
[
  { "name": "경험치 쿠폰", "icons": ["EXP_2", "EXP_3", "EXP_4"] },
  { "name": "VIP", "icons": ["VIP"] }
]
```

- `icons`에 **여러 개**를 넣으면 한 묶음(변형)이 됩니다.
  경험치 쿠폰처럼 한 번에 하나만 켜지지만 모습(배율)이 바뀌는 버프는,
  변형 중 **하나라도 감지되면 활성**, **전부 사라지면** 알림이 갑니다.
- `icons`에 **하나만** 넣으면 단독 버프입니다.
- `name` 이 화면에 표시되는 이름입니다(자유롭게 한글 등으로).
- 항목 순서가 메뉴 순서입니다.
- `BuffCatalog.json` 이 없으면 폴더의 각 PNG가 단독 버프로 처리됩니다(폴백).

## 아이콘 권장 사항

- 숫자 오버레이가 없는 **깨끗한 아이콘**을 넣으세요.
  (라이브 화면의 남은 시간 숫자는 OpenCV 매칭이 알아서 견딥니다)
